## Informatique Graphique : travaux pratiques (C++ / OpenGL)

Programmes réalisés pendant le cours d'informatique graphique : rendu 3D temps réel, maillages, simulation physique, éclairage et textures, ainsi qu'un court-métrage d'animation 3D en projet final.

> Les TP s'appuient sur le framework `sfmlGraphicsPipeline`, fourni par les enseignants. Il n'est pas inclus dans ce dépôt : seuls les programmes des TP et du projet sont publiés ici.


### Organisation 


   TP1 → Tutoriel, installation, compilation de shaders, rendu, affichage             
   TP2 → Génération procédurale de maillage (cylindre), matrices de transformation
   TP3 → Modélisation hiérarchique                       
   TP4 → Animation basée physique, particules soumises à la gravité et à l'amortissement            **[Vidéo billard, interraction d'objets](https://youtu.be/l9K5UhVAdug)**
   TP5 → Illumination locale, éclairage de Phong avec lumière directionnelle                
   TP6 → Textures                           



### Projet : court-métrage

Court-métrage d'animation avec des tortues comme personnages principaux, réalisé en binôme et regroupant les notions du cours : animation, simulation physique, lumières, textures et matériaux. Il se lance depuis [`project.cpp`](sampleProject/project.cpp).

**[Voir la vidéo](https://youtu.be/umrc4xoZq_Q)**
